## 1. Epoch：以扩散块为单位优化 MoE 服务

**题名：** Epoch: Compiling Diffusion Blocks for Sparse MoE Serving  
**作者：** Jianian Zhu 等  
**首发与版本：** 2026-09-09，v1；按 arXiv 预印本记录。  
**原文：** [版本页](https://arxiv.org/abs/2609.09748v1) · [正文](https://arxiv.org/html/2609.09748v1)

- **问题与方法：** 同一块 token 在去噪中被反复计算。Epoch 在块开始时规划专家支持集合与数据布局，每轮更新影响解码决策的数值，并让活跃 token 的稀疏性贯穿专家计算与通信。
- **实验：** 作者在 8 张 H100、3 个 7B–100B 的扩散 MoE 模型上评估，报告相对同部署基线最高 2.7 倍端到端加速。
- **局限：** 最高加速依赖批量与模型规模；对已解码 token 的缓存存在近似，正文也讨论了刷新周期，不能概括为普遍无损加速。
- **资源：** 本期未核验官方代码。
- **研究判断：** 值得研究允许重掩码和回退的代码编辑任务中，活跃位置变化是否会破坏现有缓存收益。

## 2. ICF-DLM：把结构化数值预测转为双向去噪

**题名：** Decomposition-Guided Diffusion Language Models for Inertial Confinement Fusion Prediction  
**作者：** Xiang Zhang 等  
**首发日期：** 2026-09-07；版本与正式发表状态未核验。  
**来源：** [arXiv 摘要](https://arxiv.org/abs/2609.07756)；摘要级初筛。

- **问题与方法：** 面向聚变实验的中子率波形预测，将目标分成产额、峰值时刻和局部波形，结合双向去噪与物理指标驱动的 PPO 奖励。
- **实验：** 摘要报告使用 50K 模拟与 232 次实验数据；相比匹配的自回归 LLaMA-3-8B，峰时误差由 11.6 降到 9.2 个时间步。
- **局限与资源：** 尚未核验数据划分、消融或代码下载；这一结果不能直接证明通用文本或代码生成能力。
- **研究判断：** 可关注结构化输出中的“先决定全局约束、再补局部细节”，但迁移到软件任务仍需实验。

## 3. 移动边缘 DLM 综述：把解码优势落实到系统指标

**题名：** Diffusion Language Models for Mobile Edge Agentic AI: Foundations, Applications, and Challenges  
**作者：** Chenqi Li 等  
**首发日期：** 2026-09-04；版本与正式发表状态未核验。  
**来源：** [arXiv 摘要](https://arxiv.org/abs/2609.04778)；摘要级初筛。

- **主要内容：** 从延迟、内存、能耗、带宽及可靠性讨论 DLM 的边缘部署，覆盖压缩、推理加速、端云协同和 Agent 评估。
- **证据边界：** 这是综述；摘要中的潜在优势不能作为新系统已经获得端到端收益的实验依据。本期未核验配套资源。
- **研究判断：** 可用于整理评估维度，尤其是生成质量、延迟、能耗与通信量的联合比较。

## 4. PlaidQ：连续扩散的少步与单步代码生成

**题名：** Distilled Continuous Diffusion Language Models Can Write Code in Few Steps—or One  
**作者：** Fred Zhangzhi Peng 等  
**首发日期：** 2026-09-03；版本与正式发表状态未核验。  
**来源：** [arXiv 摘要](https://arxiv.org/abs/2609.04531)；摘要级初筛。

- **问题与方法：** 将预训练自回归模型改造成连续 token 嵌入上的双向去噪器，再做分布匹配和成对轨迹蒸馏。
- **实验：** 0.7B 模型的 16 步学生在 HumanEval、MBPP+ 上分别报告 31.78、40.49 的 pass@10；单步生成在 HumanEval 上报告 7.07 的 pass@1。
- **局限：** pass@10 与 pass@1 不能直接比较；少步不等于相同比例的实际延迟下降，单步可生成正确程序也不代表高成功率。
- **资源：** 摘要提供[作者仓库](https://github.com/pengzhangzhi/plaidq)，但本次 GitHub 访问返回 404，未确认代码和权重可下载。
- **研究判断：** 适合考察蒸馏是否损失填空约束满足、编辑保留能力或候选多样性。

## 5. PILL：减少填空任务的长度搜索开销

**题名：** Predict, Don't Iterate: Efficient Adaptive-Length Infilling for Diffusion Language Models  
**作者：** Haobo Xu 等  
**首发日期：** 2026-09-02；版本与正式发表状态未核验。  
**来源：** [arXiv 摘要](https://arxiv.org/abs/2609.02108)；摘要级初筛。

- **问题与方法：** DLM 填空通常需预设中间片段长度。PILL 用探测式方法减少对初始长度的依赖及额外前向计算。
- **实验：** 摘要称覆盖 5 个 DLM、8 个填空基准；相对最强基线，代码平均通过率提高 4.8、文本 BLEU-2 提高 6.0，运行速度为 1.82 倍。指标刻度和具体设置待全文核验。
- **局限与资源：** [作者仓库](https://github.com/Hsu1023/PILL)存在，但本次读取返回“仓库为空”；不能据摘要认定已可复现。
- **研究判断：** 对代码补全和局部编辑直接相关，值得比较长度预测错误是否造成过度编辑或遗漏必要修改。

## 6. Q-Skew：微调 DLM 的隐私评估

**题名：** Membership Inference in Fine-tuned Diffusion Language Models via Token-level Memorization Asymmetry  
**作者：** Shengfang Zhai 等  
**首发日期：** 2026-09-01；版本与正式发表状态未核验。  
**来源：** [arXiv 摘要](https://arxiv.org/abs/2609.00873)；摘要级初筛。

- **问题与方法：** 研究 token 级记忆不对称，并提出基于分位数加权偏度的成员推断指标 Q-Skew。
- **实验与边界：** 摘要称在多种微调数据与模型上优于已有基线，但未提供足够细节供本期核验数值、设置与复现条件。
- **资源：** 本期未核验官方代码。
- **研究判断：** 私有代码或企业语料微调应额外评估训练数据泄露；更好的生成指标并不能替代隐私评测。
