## 跟踪范围

| 方向 | 关注问题 |
| --- | --- |
| 基础建模 | 离散、掩码与连续扩散；训练目标；扩散与自回归的结合 |
| 推理与服务 | 解码顺序、重掩码、动态长度、缓存、蒸馏、MoE、质量与延迟 |
| 推理能力与对齐 | 数学推理、可控生成、后训练、强化学习与可靠性 |
| 代码与软件工程 | 代码生成、填空、编辑、修复、测试和仓库级任务 |
| 应用与评估 | Agent、科学应用、隐私、数据集与可复现评测 |

## 每日调研规则

1. 优先检索 arXiv 原文、OpenReview、正式会议论文集及作者官方项目。核对首发日期和版本更新时间，区分预印本、作者声称录用与正式发表。
2. 每期优先覆盖上次成功检索之后的新论文与实质更新，并回看最近 7 天以补充索引延迟带来的遗漏。按 arXiv ID（去掉版本后缀）、DOI 和规范题名去重。
3. 选择最相关的至多 8 篇，不强求每天有新论文。补录旧论文必须标明；版本更新必须说明变化，不能重复旧摘要冒充新增。
4. 使用中文概述研究问题、核心方法、关键实验、局限、代码与数据可得性。明确区分论文结论和研究判断；仅获得摘要时明确标注，不补写未读实验。
5. 日报存放于 `daily/YYYY-MM-DD.md`，同步维护本页归档和论文总表。当天再次执行时更新同一篇日报。
6. 若无相关新增，仍保留简短日报，说明检索范围；若检索失败或来源不可访问，记录实际失败范围，不能表述成“没有新论文”。
