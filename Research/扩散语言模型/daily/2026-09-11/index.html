    1. Epoch：以扩散块为单位优化 MoE 服务

    题名： Epoch: Compiling Diffusion Blocks for Sparse MoE Serving
    作者： Jianian Zhu 等
    首发与版本： 2026-09-09，v1；按 arXiv 预印本记录。
    原文： 版本页 · 正文

    • 问题与方法： 同一块 token 在去噪中被反复计算。Epoch 在块开始时规划专家支持集合与数据布局，每轮更新影响解码决策的数值，并让活跃 token 的稀疏性贯穿专家计算与通信。
    • 实验： 作者在 8 张 H100、3 个 7B–100B 的扩散 MoE 模型上评估，报告相对同部署基线最高 2.7 倍端到端加速。
    • 局限： 最高加速依赖批量与模型规模；对已解码 token 的缓存存在近似，正文也讨论了刷新周期，不能概括为普遍无损加速。
    • 资源： 本期未核验官方代码。
    • 研究判断： 值得研究允许重掩码和回退的代码编辑任务中，活跃位置变化是否会破坏现有缓存收益。

    2. ICF-DLM：把结构化数值预测转为双向去噪

    题名： Decomposition-Guided Diffusion Language Models for Inertial Confinement Fusion Prediction
    作者： Xiang Zhang 等
    首发日期： 2026-09-07，v1；未核验正式会议或期刊发表。
    来源： arXiv 摘要；摘要级初筛。

    • 问题与方法： 面向聚变实验的中子率波形预测，将目标分成产额、峰值时刻和局部波形，结合双向去噪与物理指标驱动的 PPO 奖励。
    • 实验： 摘要报告使用 50K 模拟与 232 次实验数据；相比匹配的自回归 LLaMA-3-8B，峰时误差由 11.6 降到 9.2 个时间步。
    • 局限与资源： 尚未核验数据划分、消融或代码下载；这一结果不能直接证明通用文本或代码生成能力。
    • 研究判断： 可关注结构化输出中的“先决定全局约束、再补局部细节”，但迁移到软件任务仍需实验。

    3. 移动边缘 DLM 综述：把解码优势落实到系统指标

    题名： Diffusion Language Models for Mobile Edge Agentic AI: Foundations, Applications, and Challenges
    作者： Chenqi Li 等
    首发日期： 2026-09-04，v1；未核验正式会议或期刊发表。
    来源： arXiv 摘要；摘要级初筛。

    • 主要内容： 从延迟、内存、能耗、带宽及可靠性讨论 DLM 的边缘部署，覆盖压缩、推理加速、端云协同和 Agent 评估。
    • 证据边界： 这是综述；摘要中的潜在优势不能作为新系统已经获得端到端收益的实验依据。本期未核验配套资源。
    • 研究判断： 可用于整理评估维度，尤其是生成质量、延迟、能耗与通信量的联合比较。

    4. PlaidQ：连续扩散的少步与单步代码生成

    题名： Distilled Continuous Diffusion Language Models Can Write Code in Few Steps—or One
    作者： Fred Zhangzhi Peng 等
    首发日期： 2026-09-03，v1；未核验正式会议或期刊发表。
    来源： arXiv 版本页 · 方法与实验正文。

    • 问题与方法： 将预训练自回归模型改造成连续 token 嵌入上的双向去噪器，再做分布匹配和成对轨迹蒸馏。正文确认以 Qwen3-0.6B 为起点，训练 380k 步、约 0.40T 个序列位置；该数量不应自动等同于有效非填充 token 数，且模型转换并非免训练。
    • 实验： 0.7B 模型的 16 步学生在 HumanEval、MBPP+ 上分别报告 31.78、40.49 的 pass@10；单步生成在 HumanEval 上报告 7.07 的 pass@1。
    • 局限： pass@10 与 pass@1 不能直接比较；少步不等于相同比例的实际延迟下降，单步可生成正确程序也不代表高成功率。
    • 资源： 摘要提供作者仓库，但本次 GitHub 访问返回 404，未确认代码和权重可下载。
    • 研究判断： 适合考察蒸馏是否损失填空约束满足、编辑保留能力或候选多样性。

    5. PILL：减少填空任务的长度搜索开销

    题名： Predict, Don't Iterate: Efficient Adaptive-Length Infilling for Diffusion Language Models
    作者： Haobo Xu 等
    首发日期： 2026-09-02，v1；作者在 arXiv 备注主会 EMNLP 2026 录用，尚未独立核验正式发表。
    来源： arXiv 版本页 · 方法与实验正文。

    • 问题与方法： 冻结主模型，用轻量探针预测长度，展开少量长度候选并以隔离注意力并行解码，再做一次事后评分。预测与评分共增加两次前向；“冻结主模型”不代表长度探针不需训练。
    • 实验： 正文覆盖 5 个 DLM、8 个填空基准；相对 CAL，代码平均通过率提高 4.8 个百分点、文本 BLEU-2 提高 6.0，摘要报告 1.82 倍速度。实验使用单张 A40；主表的基线按初始长度 4/8/16/32 平均，不能泛化为每个长度设置都领先。Oracle 选择使用真值评估，只是候选上界。
    • 局限与资源： 作者仓库存在，但本次读取返回“仓库为空”；不能据摘要认定已可复现。
    • 研究判断： 对代码补全和局部编辑直接相关，值得比较长度预测错误是否造成过度编辑或遗漏必要修改。

    6. Q-Skew：微调 DLM 的隐私评估

    题名： Membership Inference in Fine-tuned Diffusion Language Models via Token-level Memorization Asymmetry
    作者： Shengfang Zhai 等
    首发日期： 2026-09-01，v1；作者在 arXiv 备注 EMNLP 2026 Findings，尚未独立核验正式发表。
    来源： arXiv 摘要；摘要级初筛。

    • 问题与方法： 研究 token 级记忆不对称，并提出基于分位数加权偏度的成员推断指标 Q-Skew。
    • 实验与边界： 摘要称在多种微调数据与模型上优于已有基线，但未提供足够细节供本期核验数值、设置与复现条件。
    • 资源： 本期未核验官方代码。
    • 研究判断： 私有代码或企业语料微调应额外评估训练数据泄露；更好的生成指标并不能替代隐私评测。

    7. Routing by Reasoning Need：按轨迹分配解码动作（回看补录）

    题名： Routing by Reasoning Need: Trajectory-Aware Decoding Control for Diffusion Vision-Language Models
    作者： Yixiang Liu、Zhongxing Xu、Zhonghua Wang、Xiaoying Tang
    首发 / 已核验最新版本： 2026-09-10 09:41:19 UTC，v1。
    发表状态： arXiv 预印本；作者备注 Findings of EMNLP 2026 录用，正式论文集未独立确认。
    来源： 版本页 · 正文。

    • 问题与方法： 在冻结的 LLaDA-V 上，根据中间答案稳定性、视觉/格式信号和表征变化，把样本分流为提前提交、保留原解码、支持更多推理，而非统一缩短输出。
    • 实验条件： 正文表 1 在同一模型和原始解析器下报告 ScienceQA-IMG 准确率 88.60%，对照 Len128 为 75.31%、Len2 为 84.28%。
    • 局限： 仅验证一个模型，部分配置依赖基准；视觉注意力不是正确性证明，离线轨迹选择不能直接支持在线延迟收益。
    • 代码 / 数据： 未定位可核验的作者代码发布；评估使用已有视觉问答基准，本次未下载数据。
    • 研究判断： 对代码编辑可启发“何时提交、继续修改或回退”的控制，但需执行反馈验证，不能直接迁移视觉正确率结论。

    8. Thinking with Looped Flows：以局部去噪训练循环状态（关联方法，回看补录）

    作者： Ayhan Suleymanzade、Chanhyuk Lee、Floor Eijkelboom、Nicholas M. Boffi、İsmail İlkan Ceylan、Jinwoo Kim
    首发 / 已核验最新版本： 2026-09-10 16:52:54 UTC，v1；按预印本记录。
    来源： 版本页 · 正文。

    • 问题与方法： 用共享噪声及递减噪声水平关联局部去噪目标，使循环状态在短反传窗口下传递计算；推理时将去噪器与循环状态组成流积分。
    • 实验条件： 5–7M 模型；表 1 的 ARC-AGI-½ 指标是 pass@2，分别为 58.8±1.8% 和 12.2±1.9%，不能写成单次作答准确率。不同集成轨迹预算另列比较。
    • 范围与局限： 主要验证数独、迷宫、ARC 等任务，不是通用语言或代码模型；采用既有任务协议，未证明跨任务语言迁移。
    • 代码 / 数据： 未定位可核验的作者实现；沿用既有推理基准，本次未下载或复現。
    • 研究判断： 对连续 DLM 有启发的是跨去噪步传递状态的训练方式，而非把小模型基准成绩直接与通用 LLM 排名比较。

    9. Let It Go or Learn to Self-Correct：减少早期错误锁定（关联方法，回看补录）

    完整题名： Let It Go or Learn to Self-Correct: Continuous Diffusion for Constrained Discrete Tasks
    作者： Mariia Drozdova、Stéphane Liem Nguyen、François Fleuret
    首发 / 已核验最新版本： 2026-09-08 16:45:52 UTC，v1；预印本。作者备注主要结果在 2026 年 5 月已取得，不改变此次 arXiv 首发日期。
    来源： 版本页 · 正文。

    • 问题与方法： 标准采样可能延续早期离散错误。Tweedie reprojection 从干净预测重采样；自纠错训练则让模型接触自身预测诱发的状态，缓解训练与推理分布偏差。
    • 实验条件： 在相同检查点的 21-clue one-hot Sudoku 设置，替换采样器使有效率约从 31% 升至 95%；增加自纠错训练后的 DDPM 约为 87%。这些是特定约束任务结果。
    • 局限： 与语言生成有关的是错误锁定机制，不是已证明的语言能力；文中部分外部基线比较未匹配计算预算。
    • 代码 / 数据： 正文承诺官方代码，本次 GitHub 确认仓库为空；数据生成和划分描述可读，尚不能据此称端到端可复现。
    • 研究判断： 可用带编译/测试约束的局部代码修复检验重采样收益，同时控制编辑保留率和采样预算。

    下一步精读与研究问题

    1. 解码控制是否需要任务相关信号？ 精读 Routing by Reasoning Need，比较“提前提交 / 保持 / 继续修订”与固定预算；迁移代码编辑时报告测试通过率、回归率及实际墙钟时间。
    2. 长度候选选择的上限与实际差距在哪里？ 精读 PILL，分离长度预测错误与候选评分错误，并与真值 Oracle 上界区分；同时保留首次快照提出的 PlaidQ 蒸馏后填空与保留能力检查。
    3. 自生成错误状态能否改善自纠错？ 对照 Let It Go 与 Looped Flows 的思路，在相同训练/采样预算下检验代码约束满足；另外保留 Epoch 在重掩码、动态长度和回退情况下的缓存有效性问题。

    以上均为研究判断和待验证问题，不构成创新性结论。本轮精读优先项为 Routing by Reasoning Need 与 PILL。
