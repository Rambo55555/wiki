    1. RMDM：用一次采样的全局语义变量协调并行 token 更新

    题名： Representation-based Masked Diffusion Model
    作者： Yangrong Hu、Ding Huang、Xueyu Zhou、Jian Huang
    首发 / 更新 / 已核验版本： v1 于 2026-09-11 03:00:52 UTC 提交；进入 2026-09-14（UTC）的 arXiv 公告批次并在上次截止后可见；截至本期仍为 v1。
    发表状态： arXiv 预印本；版本页没有会议录用或正式发表声明。
    原文： 版本页 · HTML 全文 · PDF

    • 研究问题（论文事实）： masked diffusion model 在同一步独立更新多个掩码位置时，逐位置边缘分布没有显式刻画这些位置之间的依赖，容易缺少全局协调。论文以条件总相关量及 KL 分解描述这一“Conditional Dependency Gap”。
    • 核心方法（论文事实）： RMDM 先用预训练编码器把完整文本映射到连续语义表示，再以 MeanFlow 学习该表示分布与高斯先验之间的可逆变换；masked diffusion decoder 通过 AdaLN 接收全局变量。生成时只需从标准高斯采样一次全局变量，随后并行去噪；预训练编码器和 MeanFlow 编码方向不在推理环中运行。
    • 训练与比较条件（论文事实）： decoder 为 12 层 DiT（hidden size 768、12 heads）。LM1B 使用长度 128、BERT tokenizer 与 BERT-Base 表征；OpenWebText 使用长度 1024、Qwen2 tokenizer 与 Qwen3-Embedding-0.6B 表征压缩至 32 维。作者重训 MDLM 与 SEDD，并保持 tokenizer、backbone、预处理和优化设置一致；但 RMDM 独有外部预训练编码器提供的语义知识，因此不属于完全等信息比较。
    • 关键实验（论文事实）： OpenWebText 无条件生成在 256 步时，RMDM 的 GPT-2 GenPPL 为 45.08，重训 MDLM/SEDD 为 72.85/75.52；16 步时为 126.58，对比 213.44/226.39。两类 LLM judge 的综合评分也随步数降低保持优势。以 GenPPL 不高于 50 为条件，在单张 A800、batch 8、长度 1024 的作者实现中，RMDM 为 287 tok/s、MDLM 为 80 tok/s（约 3.6×）；相同步数下 RMDM 约慢 10%，显存为 18.93 GB 对 18.64 GB。
    • 训练代价与局限（论文事实）： OpenWebText 设置用 4×A800；MDLM 训练 50K 步约 3 天 5 小时，RMDM decoder 约 5 天，MeanFlow 另约 1 天 15 小时。实验只覆盖无条件生成、GPT-2 量级 backbone 和有限预算；条件生成、更大模型及代码/推理任务未验证。LM1B 结果可能受 PAD 结构影响；OpenWebText 质量评测只有 256 个样本并依赖 GPT-2 PPL 与模型裁判。
    • 代码与数据： 论文与版本页未给作者官方代码、权重或数据仓库；题名/作者定向检索也未定位官方项目。LM1B、OpenWebText 及预训练编码器是外部公开资源，不能据此称本文产物已开放。
    • 与本方向关系 / 研究判断： 这是直接的 masked dLLM 方法，把连续潜变量与离散去噪结合以改善少步并行协调。待验证判断： 应在相同外部知识、总训练 FLOPs 和推理预算下，与其他 latent-guided dLLM 比较，才能判断收益来自全局变量结构还是额外编码器知识。

    题名： Distilled Continuous Diffusion Language Models Can Write Code in Few Steps—or One
    作者： Fred Zhangzhi Peng、Kaiwen Zheng、Anru R. Zhang
    首发 / 更新 / 已核验版本： v1 于 2026-09-03 22:42:57 UTC 提交；v2 于 2026-09-10 17:58:16 UTC 更新并撤稿。此前总表误记为 v1，本期更正为当前 v2。

    原文与资源： 当前版本页与历史 · 作者原给出的代码地址

    • 代码与数据： 版本页仍声称代码和检查点可用，但所给 GitHub 地址返回 404；未找到可下载权重。本期按“作者宣称开放、实际不可核验”记录。

    3. Flow Duality：源分布几何决定类别 token 的跃迁时机

    题名： Flow Duality and Source Geometry for Categorical Generation
    作者： Etrit Haxholli
    首发 / 更新 / 已核验版本： v1 于 2026-09-09 22:05:47 UTC 提交；截至本期仍为 v1。该论文位于近七日回看窗，属于漏收补录，不是 2026-09-13 新论文。
    发表状态： arXiv 预印本；版本页无会议录用或正式发表声明。
    原文： 版本页 · HTML 全文 · PDF

    • 研究问题（论文事实）： 连续 flow matching 与离散类别 flow 通常分开构造；论文问：对 one-hot 目标的连续凸插值路径逐位置取 argmax，何时能严格诱导出离散凸插值路径，以及连续源分布如何影响类别跃迁时间。
    • 核心方法（论文事实）： 在 lifted coupling、坐标置换对称的乘积连续源、以及 tie hyperplane 不带质量等条件下，作者给出连续路径经 argmax 投影到离散路径的对偶关系，并推导 Gaussian、bounded uniform、centered negative-exponential 三类源的离散插值系数。Gaussian 的跃迁随词表扩大而延后；负指数源的系数不依赖词表大小。
    • 关键实验与比较条件（论文事实）： OpenWebText 语言建模 pilot 固定同一两时间去噪架构和超参数，只训练 10K 步并做一步生成，且每个设置只有一次运行。Gaussian、centered negative-exponential、shifted uniform 的 GenPPL 分别为 428.88、258.51、244.68；熵为 4.148、4.022、4.050；基于 unigram entropy 的估计 KL 为 1.913、1.533、1.447。作者明确把结果定位为单一 operating point 的初步迹象，而非完整质量—计算前沿。
    • 局限（论文事实与证据边界）： pilot 很小、训练短、无多随机种子或大模型；估计 KL 使用粗粒度 unigram proxy。源族、位置和尺度在小实验中可能相互混杂；理论结论也依赖对称性、耦合及边界正则条件，不能直接外推到任意 learned source 或现代大规模 dLLM。
    • 代码与数据： 版本页和正文未给作者官方代码或数据入口；OpenWebText 为外部数据。本期未复现实验。
    • 与本方向关系 / 研究判断： 该工作是连续流与离散 token 生成之间的基础理论连接。待验证判断： 若在相同网络、训练预算和 schedule 下扩大词表并控制源尺度，非 Gaussian 源是否持续改善少步质量，是最直接的后续检验。

    综合判断与可执行研究问题

    RMDM 与 Flow Duality 分别从“条件依赖”和“源几何”解释少步类别生成的困难：前者增加全局语义条件以协调同一步 token，后者改变连续源到离散跃迁的时间结构。二者尚未在相同架构和预算下交叉验证。以下均为待验证判断，不是创新性定论。

    1. 隔离全局变量的净贡献： 在相同预训练编码器知识、数据、decoder 参数和总训练 FLOPs 下，对比 RMDM、直接 pooled-embedding 条件和无 latent 的 MDLM；同时报告 GenPPL、语义一致性、训练成本和同一步数墙钟。
    2. 源几何 × 词表 × 步数： 将 Gaussian、bounded uniform 与 centered negative-exponential 源接入现代 masked/flow language model，系统改变词表大小和 ¼/16/64 步预算，验证理论中的跃迁时机是否预测真实质量。
    3. 条件代码生成压力测试： 把全局 latent 与非 Gaussian source 用于代码填空/局部编辑，使用编译、单测和非目标区域保持率替代纯模型裁判，并与块扩散及 AR verifier 方法比较端到端吞吐。

    精读优先： RMDM（方法、消融与成本信息较完整）与 Flow Duality（提供可检验的理论—实验桥梁）。
