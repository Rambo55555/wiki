    1. DA-DLM：用位置 DAG 补回同一步 token 间的条件依赖

    题名： DA-DLM: Explicitly Modeling Token Dependencies in Diffusion Language Models
    作者： Pengyu Ji、Zichen Zhang、Xiang Hu、Kewei Tu
    首发 / 更新 / 已核验版本： v1 于 2026-09-14 05:39:12 UTC 提交；在上次截止后的 arXiv 公告批次进入分类页；截至本期仍为 v1。
    发表状态： arXiv 预印本。作者仓库 README 自述为“EMNLP2026 paper”，但 arXiv 未作此声明，本期也未在正式论文集确认，故仅记为作者项目自述。
    原文与项目： 版本页 · HTML 全文 · PDF · 作者仓库

    • 研究问题（论文事实）： masked/block diffusion 在一次前向中独立预测多个位置，忽略了这些 token 的条件依赖，可能把多个各自高概率但彼此不兼容的局部选择拼到一起；作者把它与非自回归翻译的 multi-modality 问题联系起来。
    • 核心方法（论文事实）： DA-DLM 为每个仍被 mask 的输出位置配置 K 个候选节点，以已经确定的 token 作为锚点，在相邻位置候选间学习转移分数。前向算法以 O(NK²) 对所有路径求边缘，Viterbi 或采样得到相互协调的序列；发射与转移联合置信度还用于选择下一轮重掩码/提交位置。固定位置分组避免传统 DAT 的动态长度路径与迭代去噪发生冲突。
    • 训练与比较条件（论文事实）： 从 BD3LM block-wise 模型继续训练 150K 步；论文也提供 FLOP-matched 的 BD3LM-300K 对照。LM1B/OpenWebText 做条件重构和开放生成，另在 XSum、CNN/DailyMail 上做摘要；不同 block size 共同比较 MDLM、BD3LM 与自回归模型。DA-DLM 的路径边缘分数不是标准 NELBO，论文也没有把它转换成可与 AR exact NLL 直接等价的 perplexity。
    • 关键实验（论文事实）： LM1B/OpenWebText 的作者报告分数从 BD3LM 的 3.39/3.04（block 4）降至 3.24/2.86；OpenWebText 少步生成在 block 16、16 次前向时 MAUVE 从 0.535 提升到 0.786，8 次前向时从 0.105 提升到 0.367。XSum 与 CNN/DailyMail 的平均 ROUGE 也高于同设置 BD3LM。单张 A800、batch 32、block 16 时，作者实现每次前向 29.60 ms，对比 BD3LM 27.59 ms（约 7.3% 额外延迟），峰值显存约增加 2%。
    • 局限（论文事实与证据边界）： 规模较小，只覆盖语言建模、开放生成和摘要，未验证数学、代码、Agent 或超长上下文；候选扩展会增加训练 FLOPs，且路径分数与 NELBO/AR NLL 的语义不同。尽管 FLOP-matched 对照仍有收益，大模型上的质量—延迟前沿尚未知。
    • 代码与数据： 摘要称代码已公开，但仓库当前只有 LICENSE 与约一行“code coming soon”的 README，没有模型、训练/推理代码或复现脚本。LM1B、OpenWebText、XSum、CNN/DailyMail 是外部数据。
    • 与本方向关系 / 研究判断： 这是直接针对 dLLM 同步预测独立性假设的结构改造。待验证判断： 必须在相同质量约束下把 DAG 路径开销、减少的去噪步数与 batch/长度扩展一起计入，才能判断其服务端净收益。

    2. Temporal Self-Distillation：让早期去噪分布预测模型最终会提交的 token

    题名： Temporal Self-Distillation: Faster Inference in Discrete Diffusion Language Models
    作者： Shijian Xu、Andrea Miele、Metod Jazbec、Volker Roth、Eric Nalisnick、Ilija Bogunovic
    首发 / 更新 / 已核验版本： v1 于 2026-09-14 07:59:45 UTC 提交；截至本期仍为 v1。
    发表状态： arXiv 预印本；版本页没有录用或正式发表声明。
    原文： 版本页 · HTML 全文 · PDF

    • 研究问题（论文事实）： dLLM 在低 NFE（前向次数）下激进并行提交会明显掉点；已有置信度蒸馏通常需要离线教师轨迹和两阶段训练。论文问能否只用当前策略自己的时间轨迹，把最终较成熟的判断提前到早期去噪步。
    • 核心方法（论文事实）： 对每个 token，将较早时刻的预测分布与该 token 最终被提交时同一模型的分布对齐，使用 β = 0.5 的 Jensen–Shannon divergence，并用单时间点 Monte Carlo 降低代价；reward weighting 与长度感知权重把训练集中到成功轨迹和较晚提交位置。教师信号来自 on-policy 自身，不需要单独离线教师。
    • 训练与比较条件（论文事实）： 数学和代码从 LLaDA-8B-Instruct 初始化，Countdown/Sudoku 从经 RL 后训练的 GDSD-LLaDA 初始化；LoRA rank 64，在 2 张 A100/H200 上约训练 3K 步。七个 benchmark 为 GSM8K、MATH500、Countdown、4×4 Sudoku、HumanEval、MBPP、LiveCodeBench v5（516 题）；所有方法沿 Fast-dLLM decoder 的置信度阈值扫描质量—NFE 曲线，只有可得官方 checkpoint 的任务才比较 dParallel。
    • 关键实验（论文事实）： 论文曲线显示，MBPP/HumanEval 在约 45 NFE 附近可达到约 50%/40% pass rate，基模型要更多前向才能到相近水平；GSM8K 在约 35–50 NFE 达到约 80%，而基模型高点约 65%。Countdown 在约 20 NFE 接近 80%，基线峰值需要约 100 NFE；Sudoku 在 25 NFE 内约 86%–89%。这些是质量—计算曲线读数，不应当写成跨实现墙钟加速。
    • 局限（论文事实）： 方法主要把模型已经学会的行为提前，并不创造新能力；低预算收益可能以高预算峰值为代价。MATH500 增益较小且基模型仍有更高峰值，canvas 长度从训练设置变化时也会掉点。不同任务使用的初始化和硬件并不完全相同。
    • 代码与数据： 论文没有给作者官方代码、模型或训练轨迹入口；所引用数据集及 GDSD checkpoint 属于外部资源。本期未独立运行曲线。
    • 与本方向关系 / 研究判断： 这是少步解码和蒸馏的直接方法。待验证判断： 需要统一 wall-clock、batch、序列长度和置信度校准后再与离线教师蒸馏比较，NFE 降低不能自动等价为同幅端到端加速。

    3. DenMark：用临时 rollout 为未完成语义单元提供水印前瞻

    题名： DenMark: Robust Semantic Watermarking for Diffusion Language Models
    作者： Tianhao Ma、Weihao Xuan、Dong-Dong Wu、Farshid Nooshi、Takashi Ishida、Gang Niu、Naoto Yokoya、Masashi Sugiyama
    首发 / 更新 / 已核验版本： v1 于 2026-09-13 03:37:48 UTC 提交；在上次截止后的公告批次进入分类页；截至本期仍为 v1。
    发表状态： arXiv 预印本；版本页无会议录用或正式发表声明。
    原文与项目： 版本页 · HTML 全文 · PDF · 第一作者同名仓库 · v0.2.0 release

    • 研究问题（论文事实）： AR 语义水印可以先生成完整语义单元再打分；dLLM 中间状态的单元尚未完成，token 更新顺序又可变，不能直接套用该流程。
    • 核心方法（论文事实）： DenMark 把输出划成固定 token region，对局部候选更新做临时条件 rollout，以估计这个未完成区域最终的语义；密钥控制的语义编码器据此偏向特定语义分区。检测端扫描多个候选单元大小并校准统计量，以抵抗改写造成的边界移动。
    • 实验与比较条件（论文事实）： 在 LLaDA-8B、LLaDA1.5-8B、LLaDA2.0-mini、Dream 四个 backbone，FinanceQA、AlpacaFarm、LongFormQA 三类数据，以及 rewrite/compression/expansion 和整文 paraphrase 四类攻击上比较 DLM-KGW、DGMark、PatternMark、UMR。主要语义攻击和质量裁判依赖 GPT-4o-mini；附录另含 Parrot、DIPPER、回译及 token 攻击。检测校准使用 30K C4 文本，另有 10K held-out negatives。
    • 关键实验（论文事实）： 48 个 backbone–dataset–attack 组合平均下，DenMark 在 FPR 0.5%/1%/5% 时的 TPR 为 63.55%/71.89%/87.45%，AUC 0.9693；论文中最强基线对应为 35.16%/41.90%/61.80%，AUC 0.8915。作者还报告质量代理（Qwen2.5-32B PPL 与 GPT-4o-mini judge）优于所测基线。
    • 效率与局限（论文事实及研究判断）： 单 token 时间从无水印 0.054 s 增至 DenMark 0.654 s，约 12.1×；DLM-KGW、DGMark、PatternMark、UMR 分别为 0.118/0.236/0.089/0.070 s。论文没有单独 Limitations 节。研究判断： 显著 rollout 开销、攻击/裁判模型依赖以及 C4 校准到其他域的迁移，都是部署前必须验证的边界；论文结果不是对任意攻击者的安全保证。
    • 代码与数据： 第一作者账号下仓库为非空实现，含 DenMark、基线、攻击、测试和复现实用脚本；v0.2.0 的 DenMark-Encoder 压缩资产可下载。数据集与四个 backbone 权重没有随仓库打包。本期确认“实际可得”，未独立执行复现。
    • 与本方向关系 / 研究判断： 这是 dLLM 生成治理和来源检测的直接工作。待验证判断： 若以固定延迟预算比较，当前鲁棒性收益可能被 12× 开销显著重排，应报告每单位 GPU 时间的检测前沿。

    4. Orthrus 复现：BF16 下“无损轨迹”并不稳定，FP32 才恢复逐 token 相同

    题名： How Lossless Is Lossless Speculative Decoding? The Role of Numerical Precision in Orthrus
    作者： Ilya Koziev、Leonid Sinev、Ivan Oseledets
    首发 / 更新 / 已核验版本： v1 于 2026-09-14 12:55:08 UTC 提交；截至本期仍为 v1。
    发表状态： arXiv 预印本；备注为“under review”，不等于已录用。
    原文： 版本页 · HTML 全文 · PDF

    • 研究问题（论文事实）： Orthrus 用冻结 AR backbone 与 diffusion drafter 并行提出多个 token，并以 intra-model consensus 声称严格无损。本文独立训练并复核：有限精度下，它是否真的产生和 AR greedy decoding 完全相同的轨迹。
    • 方法与比较条件（论文事实）： 作者以 Qwen3-1.7B 为 backbone，使用 4,113,358 条教师生成 prompt–response 样本独立训练，同时评测原作者公开 checkpoint；在 12 个领域共 1,190 个 prompt 上做最长 128 token 的 greedy trajectory 对齐，并分别运行 BF16 与 FP32。另用 lm-eval-harness 检查 GSM8K、HumanEval、IFEval。
    • 关键实验（论文事实）： BF16 时，原 checkpoint 与独立模型的逐 token 完全匹配率只有 45%/43%，且参考 AR 模型的 response-conditional perplexity 越高越容易分叉；但三个下游评测未出现系统性退化，观察到的差异没有统计显著性。把轨迹实验改为 FP32 后，1,190 个 prompt 全部精确匹配。独立模型在 12 个域中的 10 个域有更高 accepted tokens per forward，但这不代表所有硬件上的真实吞吐。
    • 局限（论文事实与研究判断）： 只测试一个 1.7B Qwen 系列、一个软件/硬件环境与 greedy decoding；没有逐层定位误差来源，也没有给出 FP32 恢复严格等价时的延迟和显存代价。研究判断： “任务分数近似无损”和“轨迹严格相同”应作为两个不同声明，不能互换。
    • 代码与数据： 正文链接原 Orthrus 的 Hugging Face checkpoint，但没有给本次独立训练模型、4.1M 教师样本或复现代码的作者入口；题名/ID 定向检索未定位可归属作者的仓库。因此摘要结论可读，独立训练链尚不能完整复现。
    • 与本方向关系 / 研究判断： 该文直接评估 AR–扩散混合服务的核心正确性声明。待验证判断： 更可靠的“无损”定义应同时固定数值格式、内核、tie-breaking、容差与下游一致性，并公布跨 GPU 的可复现测试。

    题名： CanvasAnneal: Curriculum Reinforcement Learning for Diffusion Language Models
    作者： Blake Olson、Yuhang Song、Emmett McQuinn、Yuan Shangguan
    首发 / 更新 / 已核验版本： v1 于 2026-09-11 16:59:52 UTC 提交；截至本期仍为 v1。该文位于近七日回看窗，属于漏收补录，不是 2026-09-14 首发。

    • 研究问题（论文事实）： 从全 mask canvas 开始、只依赖稀疏结果奖励的 diffusion RL 容易探索不到有效推理轨迹；直接 SFT 教师轨迹又可能固化模仿。论文希望只在训练早期借助教师，随后恢复原生全 mask 推理。
    • 核心方法（论文事实）： Gemini 3.1 Pro 离线生成约 200 词/256 token 的 reasoning trace，不含最终答案；训练开始时把 trace prefix 注入 canvas、mask 后缀，再用随训练变化的 Beta curriculum 增加被 mask 比例。prompt group 仍混入纯噪声 rollouts（数学约 75%、xLAM 约 25%）。测试时完全移除教师，从全 mask canvas 解码。

    • 代码与数据： 论文未给作者官方代码、模型或教师轨迹下载入口；定向检索未定位可归属作者的仓库。

    6. Fixed State, Long Reach：用 Mamba 状态把 block diffusion 的精确缓存变成 O(1)

    题名： Fixed State, Long Reach: What a Constant-Size Cache Buys Block Diffusion at Scale
    作者： Vaibhav Singh、Pierre-André Noël、Torsten Scholak、Eugene Belilovsky、Oleksiy Ostapenko
    首发 / 更新 / 已核验版本： v1 于 2026-09-09 23:37:47 UTC 提交；截至本期仍为 v1。该文属于近七日漏收，不是 2026-09-14 首发。
    发表状态： arXiv 预印本；版本页无录用或正式发表声明。
    原文： 版本页 · HTML 全文 · PDF

    • 研究问题（论文事实）： 全双向 dLLM 不能直接复用 AR KV cache；block diffusion 可缓存已完成块，但 attention cache 对上下文长度为 O(L)，训练后近似 retrofit 也不保证精确等价。论文问状态空间骨干能否提供与训练目标一致的固定大小状态。
    • 核心方法与训练（论文事实）： 在 Nemotron-CC 300B tokens 上以长度 1024、block size 32 和统一 single-frontier block-causal objective 预训练三个 3B denoiser：28 层 attention、28 层双向 Mamba-2，以及 5 attention + 23 Mamba 的 hybrid。三者通过同一精确 cached interface 解码；Mamba 的卷积/SSM 状态不随历史长度增长，hybrid 只保留较小 attention 斜率。
    • 关键效率实验（论文事实）： 单张 H100 80GB、BF16、CUDA graph、16 次去噪下，从 64 到 256K context 测量。256K 时 Mamba 为 6.8 ms/step、7.5 GB、约 297 tok/s；attention 为 29 ms/step、82 GB、114 tok/s，即作者报告 4.3× 低延迟、11× 低显存、2.6× 单流吞吐。batch 8 时 Mamba aggregate throughput 达 14×，而 attention 无法运行 batch 2。
    • 质量与长上下文（论文事实）： 三种模型验证 NLL 相差约 0.03 nat；八个下游任务的 attention/hybrid 平均分约 0.434/0.432，Mamba 低约 1 个点。LongBench 取每任务 20 个样本，在训练长度只有 1K 的情况下测试 2K–16K：Mamba macro 约从 11.2 降至 10.18，attention 从 7.07 降至 3.64；这更像外推诊断，不是成熟长上下文能力证明。
    • 局限（论文事实）： 只在 3B、训练长度 1024、固定 block 32 上验证；长上下文测试绝对分数低、每任务样本很少，并混有骨干和训练目标差异；没有 confidence-aware decoder。论文的“无质量代价”限于所测指标和统计精度。
    • 代码与数据： 未给三个模型、训练产物或作者代码入口；定向检索未定位可归属作者的仓库。效率数字尚未独立复现。
    • 与本方向关系 / 研究判断： 这是 dLLM 长上下文服务的直接系统设计。待验证判断： hybrid 的最佳 attention 层数应按目标上下文、batch 和质量约束联合搜索，而不是只按单流峰值选择。

    首发 / 更新 / 已核验版本： v1 于 2026-09-06 01:09:14 UTC 提交；v2 于 2026-09-11 18:39:03 UTC 更新。v2 早于前两期截止但总表仍记 v1，本期补正。

    综合判断与可执行研究问题

    本期四条线索相互补充：DA-DLM 修补空间位置间的依赖，TSD 把时间后段的预测提前，CONDOR 用共享噪声近似块级联合分布；Orthrus 复现则提醒，结构上“无损”的混合服务仍可能被数值格式破坏。DenMark 与 Fixed State 把讨论进一步推到治理开销和长上下文系统边界。以下均为待验证判断，不是创新性定论。

    1. 空间依赖 × 时间蒸馏的正交性： 在同一 BD3LM/LLaDA backbone 上做 2×2 消融（位置 DAG、TSD），固定训练 FLOPs、NFE 和墙钟，测开放生成、代码与摘要，判断两者是叠加、冗余还是相互干扰。
    2. 建立“严格无损”数值协议： 对 Uno/Orthrus 一类 AR–扩散混合解码跨 BF16、FP16、TF32、FP32 和不同 GPU/内核，分别报告轨迹一致率、任务一致率、accepted tokens/forward、延迟与能耗，并公开逐 token divergence trace。
    3. 把治理和缓存放进同一服务前沿： 在 Mamba/hybrid block diffusion 上实现 DenMark，联合扫描 context、batch、rollout 数和检测 TPR，验证常数状态缓存能否抵消语义水印的约 12× 局部开销。

    精读优先： DA-DLM（结构、FLOP-matched 对照和服务开销可形成清晰复现实验）与 Orthrus 数值精度复现（对“无损”声明给出可执行的评测拆分）。
